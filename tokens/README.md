# tokens

디자인 토큰, 아이콘 원본, 이미지 비율. **프론트 4벌이 공유한다.**

`03 §3.1`이 공유 대상으로 지정했고, `§3.2`가 컴포넌트 코드는 공유하지 않는다고 못박았다. 토큰과 자산은 공유하되 **UI 구현은 각 생태계 방식으로 독립**시킨다.

## 담을 것

- 색·간격·타이포·반경 토큰
- 아이콘 원본(SVG)
- 이미지 비율 규격 — `01 §6.1`이 "이미지 비율이 달라도 카드 높이와 정보 순서가 무너지지 않아야 한다"를 요구한다

## 담지 않을 것

React·Vue 컴포넌트, 프레임워크 전용 UI 패키지. 거대 공통 컴포넌트 라이브러리를 먼저 만들지 않는다(`04 §7.2`).
