# ADR-NNNN 결정을 한 줄로

| 항목 | 내용 |
|---|---|
| 상태 | 제안됨 / **유효** / 대체됨(→ ADR-NNNN) / 폐기됨 |
| 결정일 | YYYY-MM-DD |
| 관련 문서 | `00 §x`, `06 §y` 등 근거가 된 PRD 절 |
| 관련 ADR | 이 결정이 대체하거나 전제하는 ADR |

## 맥락

어떤 상황에서 이 결정이 필요했는가. 무엇이 정해지지 않아 막혀 있었는가.
사실만 적는다. 결정을 정당화하는 문장은 여기 쓰지 않는다.

## 결정

무엇으로 정했는가. 한 문단 안에 끝낸다.

## 근거

왜 그렇게 정했는가. **검토했으나 탈락한 대안과 탈락 이유를 반드시 함께 적는다.**
대안이 없었다면 "대안 없음"이라고 쓰고, 왜 없었는지를 적는다.

## 결과

- 이 결정으로 감수하는 것 (비용·위험·제약)
- 이 결정 때문에 새로 필요해진 후속 결정
- **번복 조건** — 어떤 사실이 확인되면 이 결정을 다시 봐야 하는가

---

*작성 규칙: 이 파일은 한 번 쓰면 고치지 않는다. 생각이 바뀌면 새 ADR을 쓰고 이 문서의 상태를 `대체됨`으로만 바꾼다.*
