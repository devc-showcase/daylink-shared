# ADR-0003 Core API 언어를 Java 21로 한다

| 항목 | 내용 |
|---|---|
| 상태 | **유효** |
| 결정일 | 2026-08-24 |
| 관련 문서 | `00 §8.1`, `06 §2`, `06 §2.1` |
| 관련 ADR | ADR-0002(스택)를 전제로 함 |

## 맥락

ADR-0002로 스택을 Spring Boot(JVM)로 정하면서 언어는 `06 §2`에 "Java 또는 Kotlin. 착수 시 ADR로 확정한다"로 열어 두었다.

Advisor 커리큘럼 v2.2 `§3.4`가 **Kotlin을 권고**했다. 근거는 다음과 같았다.

- 학습자가 TypeScript 숙련자이므로 널 안전·타입 추론·데이터 클래스·확장 함수·함수형 컬렉션이 거의 그대로 전이된다
- 순수 언어 학습 분량 추정: Kotlin 40h vs Java 55h (**Kotlin이 15h 적음**)
- 학습 대상은 언어가 아니라 `06 §8`의 트랜잭션 경계와 동시성이므로 언어에 쓰는 분량은 적을수록 좋다
- SI 현장 Java 코드를 읽는 능력은 Kotlin으로 배운 Spring 지식에서 거의 그대로 전이된다

동시에 **번복 조건 두 가지**를 함께 제시했다 — ① 상주 현장 백엔드가 Java이고 직접 수정할 가능성이 있다 ② 6개월 안에 Java 백엔드 포지션에 지원할 계획이 있다. 둘 다 "SI 실무 적용(2순위)이 학습(1순위)을 역전하는 조건"으로 규정했다.

## 결정

**Java 21 (LTS)** 로 확정한다. Advisor의 Kotlin 권고를 채택하지 않는다.

## 근거

**국내 백엔드 채용과 SI 현장에서 Kotlin 선호도가 낮다는 판단이다.** 학습 자체는 Kotlin이 가볍지만, 2순위 목적이 SI 실무 적용이므로 현장 코드와의 거리를 우선한다. 참고 자료 밀도에서도 Java가 앞선다.

즉 Advisor가 제시한 번복 조건의 취지 — 실무 적용 가치가 학습 경량화를 역전하는 상황 — 에 해당한다고 판단했다. 대신 언어 학습에 15h를 더 쓴다.

**Java 21을 택한 이유.** Spring Boot 4의 최소 요구는 Java 17이고 21·25를 권장한다. 25가 더 최신 LTS지만 **Spring 실전 자료는 21 기준이 압도적**이며, 백엔드가 기준선 없는 신규 학습 영역이므로(`00 §2.1`) 자료 밀도가 결정 변수다.

**검토했으나 탈락한 대안**

| 대안 | 탈락 이유 |
|---|---|
| Kotlin | 학습 분량 15h 절감과 TS 전이 이점이 있으나, SI 현장·채용에서의 선호도가 낮아 2순위 목적 달성이 약해진다 |
| Java 17 | Spring Boot 4의 최소 요구선이라 안전하지만, 21에서 들어온 개선을 못 쓰면서 자료 밀도 이점도 없다 |
| Java 25 | 최신 LTS지만 Spring 실전 자료가 아직 21 중심이다. 신규 학습 영역에서 자료가 얇은 쪽을 택할 이유가 없다 |

## 결과

- **학습 분량이 약 15h 늘어난다.** Advisor 커리큘럼 v2.3이 이를 반영해 M1의 언어 학습 분량을 조정했다.
- **체크 예외 위험이 새로 생긴다.** Kotlin에는 체크 예외가 없지만 Java에는 있고, Spring의 `@Transactional`은 **기본적으로 unchecked exception에서만 롤백한다.** 체크 예외를 선언하고 던지면 트랜잭션이 커밋된다. `06 §8`의 동시성·원자성 요구가 이 한 가지로 조용히 무너질 수 있다.
  - **대응**: 롤백 규칙을 후속 ADR로 명시하고, `06 §14.2`의 경합 테스트로 검증한다. 이 항목을 M1 착수 시 최우선 확인 대상으로 둔다.
- **SI 레거시와의 간극을 인지해야 한다.** 현장 레거시는 Java 8·11 + Spring Boot 2.x가 많다. Boot 2 → 3에서 `javax.*` → `jakarta.*` 네임스페이스가 바뀌었고, 현장 코드를 읽을 때 가장 먼저 마주치는 차이다. 최신으로 배우되 이 간극은 따로 인지한다.
- **번복 조건**: 없다. 이미 SI 우선으로 판단해 내린 결정이므로, 같은 근거로 되돌릴 수 없다. 다만 M1 종료 시점에 실제 언어 학습 분량이 추정(55h)을 크게 초과했다면, 그것은 언어 선택이 아니라 학습 방식의 문제이므로 ADR이 아니라 커리큘럼에서 다룬다.
