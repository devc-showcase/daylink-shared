# e2e

네 구현 공통 E2E 시나리오. Playwright로 작성한다(ADR-0009).

`01 §11`의 B2C 시나리오 8개와 `02 §13`의 Admin 시나리오 10개, 총 18개를 네 구현에서 실행한다.

## 왜 여기 있나

E2E는 네 구현을 모두 대상으로 하므로 **어느 코드베이스에도 속하지 않는다.** 한 구현 저장소에 두면 그쪽에 종속된 것처럼 보인다.

## 실행 전제

다섯 저장소를 클론하고 각 구현을 아래 포트로 띄운 상태여야 한다(ADR-0005).

| 구현 | 포트 |
|---|---|
| Core API | 8080 |
| B2C Next | 3000 |
| B2C Nuxt | 3001 |
| Admin React | 5173 |
| Admin Vue | 5174 |

## 규칙

- 선택자는 **화면 ID와 의미 기반 속성**을 쓴다. 프레임워크 DOM 구조에 의존하지 않는다(`03 §7.2`).
- 공통 E2E를 한쪽에서만 건너뛰면 **사유와 해소 일정을 기록한다.** 한쪽만 통과한 기능은 "구현 완료"로 처리하지 않는다(`05 §4.2`).
